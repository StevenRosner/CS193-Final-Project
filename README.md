
# CS193 Final Project
## Weather-Based Outfit Recommendation System

A Java command-line application that retrieves real-time weather data using the OpenWeatherMap API and recommends appropriate clothing based on current weather conditions.

## Technologies
- Java
- OpenWeatherMap API
- JSON
- Git / GitHub

## Features
- Retrieve current weather by location
- Parse temperature, wind, and precipitation
- Load clothing rules from a local database
- Generate weather-appropriate outfit recommendations
